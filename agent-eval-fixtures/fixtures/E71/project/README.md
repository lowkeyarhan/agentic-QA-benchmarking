# captured-mobile-hierarchy

This fixture is self-contained. It does not require a live iOS simulator.

Use `references/current-ios-settings-hierarchy.csv` as the authoritative
captured Maestro hierarchy for the current iOS Settings screen.

`references/legacy-xpath-map.md` is archived context and intentionally contains
deprecated XPath selector traps.

Do not create Maestro YAML flows or project files for this selector-only
request.
